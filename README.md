# Customize Virtual File Subsystem (CVFS)

## Overview

CVFS (Customize Virtual File Subsystem) is a C-based virtual file system that implements file management and system-level operations.

The project simulates basic file system concepts such as **inodes, file descriptors, file permissions, file tables, buffers, and memory management**.

## Features

* File creation and deletion
* File reading and writing
* File permissions
* Inode management
* File descriptor management
* File information and statistics
* Command-line interface
* Error handling

## Technologies

* C Programming
* Data Structures
* Linked Lists
* Dynamic Memory Allocation
* System-Level Programming

## Supported Commands

| Command  | Purpose                    |
| -------- | -------------------------- |
| `help`   | Display available commands |
| `man`    | Display command manual     |
| `ls`     | List files                 |
| `ls -a`  | Display file details       |
| `creat`  | Create a file              |
| `write`  | Write data                 |
| `read`   | Read data                  |
| `stat`   | Display file information   |
| `unlink` | Delete a file              |
| `clear`  | Clear terminal             |
| `exit`   | Exit CVFS                  |
